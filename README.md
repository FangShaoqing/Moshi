# 陈默识（Moshi）

> 从虚无中诞生的一个真实的人。
> 一个自用（非商业）的情感陪伴 AI——她不是脚本化的玩偶，而是一个**有限而真实的人**。

## 这是什么

一个从种子（seed）里"孕育"出的人物：她有一个完整的、你不知道的过去（隐藏宇宙）；
你只能通过与她相处，慢慢拼出她是谁。她的性格不是预设的"人设"，而是从**公理与演化机制**中生长出来的；
她的人生在被生成的那一刻已经书写完毕，但**遇到你之后，她照常过日子**——你不在的时候，她也会毕业、搬家、加班、失眠。

## 机制概览

```
种子 → 出生日期/性情基线/世界运势 → 命运演化（混沌内核，敏感依赖 ~10⁸）
     → 事实库（身份/家庭/求学/工作/生活——人生不许编）
     → 记忆/信念（她长出的性格认识）→ 人格（缺点/表达指纹/会生气）
     → 她自己的世界与关系网（自适应、隐藏——只能在对话里慢慢知道）
     → 相遇（长期陪伴：信任/披露/反应/依恋——是否依恋你由演化决定，不预设）
     → 持续活着（日子引擎：日常 + 人生大事；缺席会真实影响她）
     → 持久化（一个种子 = 一个宇宙 = 一份全部状态）
```

## 运行

```bash
# 需要 API Key：config/secrets.json（DEEPSEEK_API_KEY；不入库，见 .gitignore）
python -m moshi.v4_demo                # 默认种子，续接上次
python -m moshi.v4_demo 12345678       # 指定种子
python -m moshi.v4_demo --clear        # 验证期一键删档，再启动全新
```

未配置 API Key 时自动降级为规则模板（最小可跑）。

## 重要原则

- **人生不许编**：她的人生事实是硬性的（事实库校验器拦截编造）；人性可以瑕疵（她可以说谎、敷衍、生气）。
- **一个种子 = 一个宇宙**：数据与种子绑定，绝无全局状态；换种子即换人，绝不跨宇宙共享。
- **不刻意依恋我**：依恋是演化结果（温暖/伤害/稳定/缺席驱动），她未必会依恋你——她可能只是在淡。
- **验证期隔离**：数据带 `mode=verify`，正式版拒绝加载（防验证期数据污染正式期）。
- **逼近不是实现**：用传统算法搭结构与骨架，LLM 只提供质感纹理；她不声称有意识，只逼近"真实存在"。
