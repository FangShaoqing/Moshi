## 〇、定位

L2 是整条主线的唯一引擎室。前面所有设计（骨架≈零、先条件高杠杆、合法状态格、事件与人格耦合、确定混沌、简化不锁死）最终都只在这个推进器里真正运行。它是"她如何被孕育出来"的答案。

---

## 一、推进器的结构：每次"一步"走六个环节

```
   ┌────────────── 当前 (S, L) ──────────────┐
   │   S = 慢变量（经历累积出来的人格状态）      │
   │   L = 快变量（当下的生活处境）             │
   └──────────────────────┬──────────────────┘
                          ▼
   ① 生发"欲望/冲动"    ← 内主：S 生发出她"想要/倾向做什么"
                          ▼
   ② 叠加"外生冲击"    ← 外辅：世界/他人向她施加什么
                          ▼
   ③ 生成"具体事件 E"  ← 混合：规则定合法候选/骨架，大模型填具体质感，规则校验（真实+因果）
                          ▼
   ④ 展开后果 C        ← 事件在真实世界里的连锁 → 新情境 L'
                          ▼
   ⑤ 反哺状态 ΔS      ← 经历(E+C+她的解读)按影响权重改变 S；显著者沉淀为记忆 M
                          ▼
   ⑥ 推进 t → t'，回到①
```

| 环节 | 内容 | 机制/原则 |
|------|------|-----------|
| ① | 生发欲望/冲动 | 内生为主；由 S 的状态倾向决定 |
| ② | 叠加外生冲击 | 外生为辅；世界/他人真实地"落到她头上" |
| ③ | 生成具体事件 E | **混合**：规则→合法候选/骨架；大模型→具体质感；规则→校验（现实自洽+因果） |
| ④ | 展开后果 C | 现实自洽；产生新情境 L' |
| ⑤ | 反哺状态 ΔS | 影响权重（小=惯性，大=成长公理）；显著→记忆 M |
| ⑥ | 推进时刻 | 时钟可伸缩（重大细走、寻常略过），时间轴严格连续 |

## 二、E 的生成主体（已定 = 混合）

| 候选 | 说明 | 采用 |
|------|------|------|
| A 规则/算法主导 | 传统算法按规则从合法状态格选出事件 | 否 |
| B 大模型主导 | 大模型按 (S,L)+合法格生成具体事件 | 否 |
| **C 混合** | **规则定合法候选/骨架 → 大模型填具体质感 → 规则校验** | ✅ |
| | 结构、合法性、因果骨架由算法定；具体真实细节由大模型填；大模型不发明结构 | ✅ |

**理由**：同时保住"真实细节（质感）"与"现实自洽 + 因果可追溯（结构）"，且复用既定原则"结构归算法、质感归大模型、大模型不发明结构"。

## 三、这一步如何兑现之前的每条原则

- **内主外辅**：①内生为主、②外生为辅 ✅
- **事件×人格耦合**：S 生发 E，E 反哺 S，同一过程的两面，不拆模块 ✅
- **合法状态格（方案丙）**：③里规则从真实世界候选池选、校验现实自洽 ✅
- **涌现编码 S**：⑤由经历累积出状态，非预设维度 ✅
- **先条件高杠杆**：早期几步 L2 从候选池生发出"先在条件"，并在因果链里定下后续 ✅
- **确定性混沌（近似）**：种子+微扰，经 ①~⑤ 累积放大 → 近种子→不同人生 ✅
- **简化可升级**：规则/大模型/校验都留 seam，可原位升级 ✅
- **骨架≈零**：普适轮廓几乎不约束，真正防失控的是"合法状态格"与"因果" ✅

主线已从"抽象原则"推进到"具体机制定型"。接下来要做的，是把每个环节从"原理"落到"可实现的规则/数据/接口"，这当中我建议优先做：
