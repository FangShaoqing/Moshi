# 11 · 事实主干的生成机制：人生叙事时钟（草案）

> 记录日期：2026-08-27（会话进行中）
> 状态：**草案 / 待确认**。主线论述题——"大量具体生命事实（事实主干）如何用简单规则生成"。
> 承接：09（生命引擎循环）、04（只设时代、其余涌现）、06（合法状态格/方案丙）、10（简化不锁死）。
> 原则遵循：只用时代锚、其余涌现；事件内生为主/外生为辅；事件与人格耦合；事实主干为主、S为涌现编码；简化但可原位升级。

---

## 〇、主线的目标

把 (S, L) 循环真正落成"一条可被读取的、具象的生命事实序列"。即：从种子出发，沿时间轴生成一串**具体的生命事实**——她出生在哪儿/家庭怎样、成长中经历了什么、去了哪、和谁交往、发生了什么——最终停在"今天"。

---

## 一、核心机制：三层"叙事时钟"

把"一个人从出生到现在"的生成，拆成三层，逐层填充：

```
L0 叙事时钟          时间轴（出生 → age_now），决定"她活了多久、什么时候是什么年龄"
   │
L1 阶段骨架          把一生切成"必经的生命阶段类型"（轻骨架，只定义"类型"，不预设内容）
   │
L2 事实填充          每阶段内，由"状态 S + 情境 L"生发具体事件（从合法候选池选，因果推进，反哺 S）
```

### L1 · 阶段骨架（生命的"必经结构"，但要尽量轻）
- 先定义"必经的生命阶段类型"作为一种**极弱的普适轮廓**：依恋/被抚养 → 社会化 → 进入生产 → 建立亲密 → 走向当下。
- **关键修订（协作方提出）**：不仅要"类型"最弱，**连这些历程的 出现时机、持续时间、剧烈程度、具体内容 都要降到最弱约束**——全部由因果涌现，不做任何预设。
  - 极端情形完全合法：贫穷者可能**没有**一块完整的"求学"阶段，直接进入为生计奔波；青春期可能因动乱而漫长或仓促；某人可能始终漂泊、未建立固定亲密。这些**都不该由骨架决定**，而应由因果推出来。
- **定位**：骨架只承认"一个人类生命从出生到当下会涉及一些根本性的人类历程"这一**现象学事实**，其余全交因果。

### 关键澄清：先在条件（家庭/地域/身份）——**系统自由生发，非造物主设定**（协作方已确认）

- **造物主预设**：仅时代 + 时代背景（04 的 A 层最小化）。**绝不设定先条件。**
- **先在条件**：由系统生成器在生命**最早期**的 L2 步骤，从**真实世界候选池**（方案丙）**自由生发**选出——如出生地、家庭条件等。属**系统侧**。
  - **它不是"造物主心里的预设（富裕/贫穷/普通这类剧情选择器）"**，而是"生成器早期长出的、上游的因果输入"。
  - **自由生发 ≠ 纯随机**：它在"合法状态格"（时代锚框定的真实可选出身边界 + 真实世界候选池）内、受因果与时代约束地选择。
- **高杠杆**：一旦生出，会在因果链里像多米诺一样**定下后续命运**（富裕/贫穷/普通→不同人生阶段）。
- **三合一验证**：①你不预设→符合"只设时代"；②你事先不知道→符合"隐藏宇宙"；③它高杠杆→发挥"出身塑造命运"作用。三者同在此侧成立，缺一不可。

### 由此：骨架近乎为零，约束交给"合法状态格 + 因果"
- 骨架（普适生命周期轮廓）压至**最弱**：承认"人类生命会涉及一些根本历程"这一现象学事实；其 **顺序/时机/时长/剧烈程度/内容** 全部由因果涌现。
- 真正防止"失控/不合理"的不是骨架，而是 **L2 的合法状态格（时代锚 + 真实世界候选池 + 因果自洽）**。
- A/B 分叉在此**汇合**：不纠结"骨架多粗"，而是确定"骨架≈零，约束全交 L2 的合法状态格与因果"。

### L2 · 事实填充（真正的生成，方法= §09 的循环）
- 当前 "状态 S + 情境 L" → 生发"接下来发生什么/她做什么"（内生为主，外生为辅）；
- 事件从**合法候选池**（真实世界知识层，方案丙）里选，落在真实世界内、合乎因果；
- 事件展开后果 → 新情境 L' → 反哺状态 S → 推进到下一时刻。
- 这一层就是"具体生命事实"的真正来源，也是"涌现"发生的地方。

---

## 二、关键分叉（需拍板）：L1 骨架该多粗？

这是本主线的核心决策点，直接决定"事实主干"长什么样，也决定"可控性 × 模板化"的权衡：

| 选项 | L1 骨架 | 优点 | 风险 |
|------|---------|------|------|
| **A · 几乎无骨架** | 只给出生→现在，剩余纯由 L2 因果长出来 | 最涌现、最不可预测 | 可能失控、跑出不合理的轨迹（难验证） |
| **B · 轻骨架 + 事件填充**（我倾向） | 只定义"必经的阶段类型"，内容全由 L2 生发 | 既给混沌一个"时间学"框架，又不预设内容→既可控、又不太模板化 | 若骨架划分过细，退回模板化 |
| **C · 较重阶段剧本** | 每阶段预定义"该发生什么"的剧本模板，填变量 | 最可控、最清晰 | 最易模板化——所有虚拟形象骨架相同（可能削弱"陌生感/涌现"，甚至变成"标签式"） |

> **我的倾向：B（轻骨架 + 事件填充）。** 理由是它最能平衡"可控性"与"非模板化"：骨架提供"人生的必经历程"这一**普适时间结构**（人人都要成长、求学、进入社会、建立关系），但每段的**具体内容**完全由她的状态/处境/混沌生发——这既让"事实主干"不至于跑飞，又保住了"她是一个具体的人，而非模板角色"。

---

## 三、为什么这个机制能同时满足多条已定原则

- **只用时代锚、其余涌现**：L0/L1 只提供"时间线 + 阶段类型"（这部分仍在时代+年龄区间内），出生地/家庭/身份（L2）全部涌现 ✅
- **事件内生为主、外生为辅**：L2 生发 = 内主外辅 ✅
- **事件与人格耦合**：L2 一步里 E 与 S 互生，不拆模块 ✅
- **事实主干为主、S 为涌现编码**：L2 产出"事实"，S 是这些事实的读出/编码 ✅
- **简化可升级**：L1 骨架、L2 候选池选择、S 累积规则都可留 seam 原位升级 ✅
- **合法状态格（方案丙）**：L2 从真实世界候选池选，落在合法格内 ✅
