# 40 · 关系话题的隐私边界（刚认识不聊家庭/关系）

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并实测 ✅（混沌敏感保持 12.2 亿倍 / 生成正常）
> 背景：协作方测试发现——"刚聊两句就问家庭情况，默识居然都直接回答了，感觉不像刚认识。"
> 这是真实问题的（刚认识被问家人=越界，她该警觉）；且是**关系网暴露的新缺口**（她世界的人也是隐私）。

---

## 〇、根因（诚实）
1. **意图分类漏**："你妈妈最近怎么样"不含过去类关键词（"你家/爸妈"有但"妈妈"无）→ 被归 **chat** → 披露模型（只在 ask_past 生效）**放行**；
2. **隐私词缺**：`_INTRUSIVE_WORDS` 没把家庭/关系类列为隐私（只列收入/体重/前任）；
3. **披露未覆盖关系话题**：只对"过去"判披露，不覆盖"她世界的人"（她世界是隐私的一部分）。

---

## 一、修复（4 处）
1. **意图分类**：`PAST_WORDS` 补全家庭/关系词（妈妈/我妈/我爸/家人/家里/室友/朋友/同学/兄妹…）→ 归 ask_past（披露模型接管）；
2. **隐私词**：`_INTRUSIVE_WORDS` 加"你妈/你爸妈/你家人/你室友/你对象"等（**问你**的家庭/关系 = 过分打听）；
3. **披露覆盖**：`_intrusiveness` 把"妈妈/父母/家人/室友/对象"判为高/mid 侵入（刚认识问=高侵入→低分→avoid）；
4. **警觉回应**：`_template_reply` 兜底（家庭话题+avoid）→ "……怎么突然问这个？我们还不熟吧。"；**LLM prompt 强化**"刚认识被问家庭/关系 → 你会警觉、会不舒服"。

---

## 二、实测（✅ 刚认识 vs 信任深，差别真实）

**刚认识（信任 0.3，无历史）**：
```
你> 你妈妈最近怎么样？
她> （微微一怔，语气淡了一些）……还行吧。你倒是挺会问问题的，一上来就问这个。

你> 你室友是什么样的人？
她> （愣了一下，微微皱眉）怎么突然问这个...我们还不熟吧。不过她人挺好的，挺照顾我的。

你> 你家在哪？
她> （微微一愣，语气有点冷）怎么突然问这个？我们还不熟吧。
```
**信任深（0.85 + 相处很久）**：
```
你> 你妈妈最近怎么样？
她> 挺好的，在老家待着，前两天还打电话问我吃饭没。你那边呢？

你> 你室友是什么样的人？
她> 还行吧，挺安静的一个人。不像别的宿舍那样热闹，各忙各的，挺好的。
```

**关键**：同一个人，刚认识被问家庭 → **警觉/防一手**（"挺会问问题/还不熟吧"）；信任深 → **自然聊起**。她不是"有问必答的服务型 AI"，**是有边界、会防陌生人的人**。

---

## 三、意义
- **真实人际的隐私边界**回来了：刚认识问了不该问的，她会**不舒服、警觉、拒**（真实的人就是这样），而非全盘托出；
- **关系网的人也是隐私**：她世界的人（妈/室友）不因为"生成出来了"就不是隐私——她按信任决定聊不聊；
- 与"有限的人/有边界"哲学一致。

生成 / 混沌敏感 12.2 亿倍 / 降级正常。
