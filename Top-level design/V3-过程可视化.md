## 一、实现：`moshi/v3_view.py`（终端可视化）

```
python -m moshi.v3_view
```

### 展示内容（每"步"）
1. **她的状态柱状图**：6 维（愉悦/活力/主导/自我/信任/归属）用 `█` 色块表示强度——肉眼可见状态在移动。
2. **世界运势**：当前各领域顺/逆风（`信任←0.4 亲密关系→0.3 ...`）。
3. **事件叙事**：具体的事（如"被最亲近的人背叛，她第一次明白'交出去'的代价"）。
4. **变化的人话**：`这段经历后：她更无力了（主导 -0.06）；她更怀疑自己了（自我 -0.02）`
   —— 把"状态变化"翻译成人话，而非"Trust↓0.11"这种数据。
5. **混沌分离过程图**：两个"她"的轨迹距离用柱状图展示（从 0 到 0.15 肉眼可见在放大）。

### 关键改造
- 维度名用**中文**（愉悦/活力/主导/自我/信任/归属），避免"中文人生+英文数据"的割裂感。
- 新增 `dim_phrase()`：维度变化 → 人话（`Trust↓` → "她更难相信别人了"）。

## 二、过程中发现并修复的真 bug：**事件方向与净状态变化矛盾**

**现象**：24岁"被最亲近的人背叛"（逆风叙事），但状态变化却是"她更愿意相信别人（信任 +0.04）"——荒谬。

**诊断**（诚实过程）：
1. 先怀疑 `event_delta` 系数：诊断证明"信任领域、世界逆风、投入0.6"时对信任维度是 **-0.072（负向，正确）** → `event_delta` 本身没问题。
2. 根因：**多领域脉冲叠加**——24岁 actives 里"信任"（逆风）与"亲密关系"（顺风）同时贡献脉冲，亲密关系的顺风把信任维度拉成 +0.04，**净效果与主叙事方向分裂**。
3. 修复：`_note` 的顺/逆风**只取"主事件自身"的方向**（世界 r × 该领域代表性维度系数符号），而非净 delta / 世界 r 本身。→ 叙事与**主事件**因果一致，不受其他领域对冲干扰。
4. **教训**：我中间写了一段 `if False else None` 占位垃圾代码（想用没定义的变量），已立即清理重写。**占位代码不可提交**——这是对"要诚实、要可运行"的坚持。
