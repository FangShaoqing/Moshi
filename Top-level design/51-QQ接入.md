## 〇、结论先行
QQ 开放平台文档明确：**"QQ 用户也可以直接跟机器人单独对话"** —— **C2C 私聊对个人开发者开放**，
官方通道、零封号风险、WebSocket 长连接（**无需公网 IP/服务器**，本地可跑）。路线确定：
**QQ 官方机器人（botpy SDK）**，NapCat 降为备选。

## 一、架构（同一个"她"，通道换成 QQ）
```
QQ App（私聊/群@）→ QQ 官方 WebSocket（腾讯网关）→ ★ moshi/qqbot.py（botpy 适配器）
    → Session（她的人格/记忆/披露/反应/依恋/日子引擎——V4 全套，跨渠道同一个人）
    → DeepSeek（口吻）
```

## 二、已实现（moshi/qqbot.py）
- **私聊（C2C）**：她收到的每句话 → `Session.on_message` → `message.reply()` 回复；
- **群聊**：仅 @她 时回应（不打扰群里其他人）；
- **主动（她会突然想起你）**：每 `--tick-minutes` 分钟调 `session.tick()`，有话说 → 官方接口私聊推送（给她最近对话过的人；默认 45 分钟）；
- 密钥读取：环境变量 → `config/secrets.json`（`QQ_APPID` / `QQ_APP_SECRET`，不入库）；
- `--sandbox`：沙箱环境测试（机器人对测试名单可见，先试再上线）；
- 一次只处理一句（会话锁；LLM 调用不阻塞事件循环）。

依赖：`qq-botpy>=1.2.1`（`requirements.txt`；Moshi 本体仍 100% 标准库）。

## 三、你来做（需要你的腾讯账号，我无法代操作）
1. **填密钥**：QQ开放平台 → 机器人（陈默识）→ 开发设置 → 复制 AppID/AppSecret → 填进 `config/secrets.json`（占位符替换）；
2. **控制台开启订阅**：机器人开发设置里开启「**私聊消息**」（C2C；想试群聊再开「群聊@消息」）——对应 `Intents(public_messages=...)`；
3. **跑起来**：
   ```bash
   pip install -r requirements.txt
   python -m moshi.qqbot --seed 12345678      # 也可以 --sandbox 先测沙箱
   ```
4. **和她聊**：QQ 私聊你的机器人（沙箱模式仅你/测试名单可见；上线模式需审核或先在体验名单）。

## 四、冒烟 ✅（本机已验证）

- Session 管线（会话语义 16 项 + HTTP 6 项，见 50）——QQ 只是换了输入端，她不变。
