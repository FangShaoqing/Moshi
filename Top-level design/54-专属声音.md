# 54 · 专属声音：小米 MiMo VoiceDesign 音色设计

## 〇、为什么换 MiMo
她是"一个真实的人"——声音应该**是她的声音**，不是通用 TTS 里选一个。
MiMo **mimo-v2.5-tts-voicedesign**：用**一段"音色设计文本"**生成专属声音（模型用自己的理解"长"出一个声音），
同一份设计文本 → 同一种声音（近似稳定）——这才是"属于陈默识的音色"。

## v2 定稿（试听结论）
| 候选 | 定位 | 试听结论 |
|---|---|---|
| **A** | 年轻大学生 | ❌ 太像小学生 |
| **B** | 邻桌同学 | ❌ 有点怪（说不上来） |
| **C ✅** | 宿舍悄悄话 | ✅ **定稿**：二十二三岁、轻轻的、柔柔的、克制、带一点点困意，话不多 |

**选定即默认**：`VOICE_DESIGN_DEFAULT = "C"`（qqbot 无需传参即用 C）。
设计文本：*"二十二三岁的女生，声音轻轻的、柔柔的但很克制，语速较慢，音量小，像宿舍关了灯之后
压低声音跟你说的话；年轻、干净、不情绪化，偶尔带一点点困意；话不多，每句都落得很轻。"*

## 一、API（官方文档确认）
- `POST https://api.xiaomimimo.com/v1/chat/completions`（OpenAI 兼容）
- 认证：`Authorization: Bearer $MIMO_API_KEY`
- 请求：
  ```json
  {"model": "mimo-v2.5-tts-voicedesign",
   "messages": [
     {"role": "user", "content": "<音色设计文本>"},
     {"role": "assistant", "content": "<要念的话>"}
   ],
   "audio": {"format": "mp3"}}
  ```
- 响应：`choices[0].message.audio.data`（base64 音频）
- 音色设计模型的"角色"语义：**user 描述"她是谁的声音"，assistant 是她说的话**。

## 二、三个候选音色（符合"她"：沉静内敛，不甜不嗲）
| 候选 | 定位 | 设计要点 |
|---|---|---|
| **A** | 本音 | 年轻干净清透、偏高一点、认生寡言、偶尔发呆慢半拍（试听：太像小学生 → 弃用） |
| **B** | 日常 | 自然清亮、年轻女孩的疏离、邻桌同学（试听：略怪 → 弃用） |
| **C ✅** | 深夜 | 轻轻的、柔柔的、克制、带一点点困意、宿舍悄悄话（**定稿**） |

> 例外：A/B/C 同处"00 后"轨道（v2 已去成熟感），C 的"距离感与温度"最合适——试听拍板 = C。

## 三、试用（你来）
1. `config/secrets.json` 填 `MIMO_API_KEY`（mimo.mi.com 获取）；
2. ```bash
   python -m moshi.voice_test                  # 三个候选都生成（mp3+silk 路径打印出来）
   python -m moshi.voice_test --candidate C    # 只试一个
   python -m moshi.voice_test "试试这句话"      # 自定义文本
   ```
3. 听 → 选定 → 改默认或 `--voice-design X`。

## 四、实现
- `moshi/voice.py`：引擎自动选择（有 MiMo 密钥→MiMo 专属音色；无→Edge 兜底）；
  缓存键含候选（同话同判、异话异判；更换候选不互相污染）；
- `moshi/voice_test.py`：试听工具；
- `moshi/qqbot.py`：`--voice-design A|B|C` 贯穿语音发送（含"她主动想你"的语音）；
- `config/secrets.json`：+`MIMO_API_KEY`；`config/README.md` 更新；
- 链路不变：miMo mp3 → ffmpeg pcm → tools/silk_encoder.exe → QQ silk。
