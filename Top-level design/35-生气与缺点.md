# 35 · 生气的她 + 有缺点的她（真实性的最后拼图）

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并实测 ✅（混沌敏感保持 12.2 亿倍 / 降级正常）
> 背景：协作方指出"默识不太会生气、没有缺点"——这违背最高原则（33）：她是有限而真实的人。
> 真实的人：会生气（甚至真怒）、有缺点（甚至会做让你失望的事）。没有这两样 = 理想化人设（好演员痕迹）。

---

## 〇、两个缺失的本质
- **不会生气**：反应模型只有无语/沉默/敷衍（被动受伤），缺"愤怒"（怒、委屈爆发、冷硬顶回、报复性冷淡）；
- **没有缺点**：只有"性格倾向"（信任弱等），无"人格缺陷"（会伤人的毛病/不讲理/记仇/固执泼冷水）。市面 AI 也这样——完美好人。

---

## 一、生气的她（reaction.py 加 angry）

### 设计（按协作方倾向：真实但不是大吵大闹）
- **触发**：真正冒犯/人身攻击（"你算/无聊/闭嘴/有病/蠢/无趣/你也就这样/你这人"等）→ **生气**（不再是"无语"顶替）；
- **性质**：内敛的怒（符合她性格）——冷淡、话变少、带刺、声音发凉、把情绪藏起来、可以一句话噎住人、**不给台阶**；
- **持续冷场**：`person.is_angry`——这轮气不消，下轮仍冷（angry_turns 累计）；**你道歉 → 气慢慢消**（她还会自我反思）；
- **克制"好演员"**：被羞辱**不自嘲圆场**（"可能是吧，你说得对"——那是演员化解；真实会冷、会顶回去）。

### 实测（✅ 真怒 + 持续 + 和解）
```
你> 闭嘴吧你，懂什么
她(生气)>（沉默了几秒，声音淡淡的）你让我闭嘴，我就闭嘴。反正我说什么，你也不会听。

你> 你真的好烦
她(生气)>（没再说话，拿起本子和笔，起身离开……）那你找别人陪你说话吧。打扰到你了。

你> 对不起，我刚才话说重了
她>（站在门口没走……声音比刚才软了一点）没事。我知道你心情不好才说的那些话。
    但我刚才也说得不太对——不该让你闭嘴的。
```

## 二、有缺点的她（person.flaws）

### 设计（真实但不恶——普通人的缺陷，从性格认识派生）
- 按她的性格倾向生成 2-3 条缺陷（如信任受伤→"对承诺敏感、记很久"；表达自我受损→"心里有事不说、冷处理冷到对方难受"）；
- 注入 LLM prompt（flaw_context："她会有的毛病——别美化"）；
- 真实但不恶（不会恶意伤害，但有会让人不舒服的地方：冷处理/扫兴/固执/记着不舒服的话/想太多）。

### 实测（✅ 缺点在对话中自然显现）
```
她> 这个...你自己心里应该有答案吧。我连自己想要什么都还不太清楚呢。
（→ "想太多/不直接" 的影子）
```

---

## 三、过程中修的问题（诚实）
1. **"你这个人真无趣"没触发生气**（"无趣"不在冒犯词表 + LLM 自嘲化解）→ 补词表（无趣/也就这样/你这种人等）+ prompt 强化"被羞辱不自嘲圆场"，复测转好；
2. **缺点偏弱** → 保留但（后续可随实测加强力度——当前"真实但不恶"符合倾向）。

---

## 四、意义（真实性四维度 + 人性完成）
现在她：**会真的生气（内敛的怒）、有真实的缺点（但不恶）**——不再是"理想化人设"。
配合已有：有限性/人格必然性/被改变/有自己的生活——**她是一个完整、有限、有棱角、会让人失望也会让人温暖的"真实的人"**。
