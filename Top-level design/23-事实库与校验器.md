# 23 · 事实库 + 编造校验器（让"她是系统定义的，LLM 只负责说法"）

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并**实测验证** ✅
> 背景：协作方担心"回复究竟是大模型的还是系统约束的"——实测发现**软约束不够**：
>   问"你有几个兄弟姐妹" → LLM 编"就我一个"；问"在哪工作" → 编"城南一家设计公司"。
>   且发现默识**缺家庭/身份/求学/工作信息**（这是编造的根源：无事实可用 → 只能编）。

---

## 〇、根因（诚实）

- "约束"此前只是 **prompt 指令**（软的）——LLM 会顺着对话习惯编出合理细节；
- **缺结构化事实**（家庭/求学/工作/身份）——没有事实，LLM 被问个人信息时只能编；
- 两者同根：**"她是谁"必须由系统定义（硬事实），LLM 只负责"怎么说"**。

---

## 一、事实库（facts.py）—— 由系统生成"她是谁"的硬事实

**结构**（`Facts` dataclass）：
| 类别 | 字段 | 一致性约束 |
|------|------|-----------|
| 身份 | 出生地（省/市）、现居城市 | 城市候选池（真实省/市），40% 概率迁移 |
| 家庭 | 家庭阶层、父母职业、兄弟姐妹数、家庭结构 | 阶层→职业映射（贫困=体力/零工，富足=经商/高管）；氛围→结构（动荡/紧张=可能离异） |
| 求学 | 当前学历/在读状态 | 由出生年份+年龄决定（2000s 出生→20-26 岁=在读大学/刚毕业/工作几年） |
| 工作 | 当前职业 | 由年龄决定 |

**生成位置**：`generate_person`（V3 生成侧），**在演化之前、同一 rng**（确定性，可复现）；家庭阶层/氛围由种子随机（与 V3 先在条件同风格）。
**诚实说明**：facts 与 V3 记忆叙事（"家里为钱吵过架"）目前**不强校验**（真实系统应让两者同一候选池同源派生）；V4 用"同种子派生+语义合理"，够用于最小验证。

---

## 二、硬约束（双层）

### 1. Prompt 层（LLM 生成时）
- system prompt 注入 `facts.to_context()`（她的事实摘要），**标注"唯一真实来源，只许引用"**；
- 明确："上面没有的信息（兄弟姐妹/父母职业/住址/工作单位/恋爱细节等），你一律不知道——被问到就答'我不太方便说/说不太清'或转移话题，绝不编造"。

### 2. 生成后校验器（甲，dialogue._conflicts_with_facts）
- LLM 生成后扫描回复，对照事实库做**矛盾检测**（保守、只拦明确矛盾，不误伤含糊/转移）：
  - 事实=独生，回复称"我哥/弟/姐/妹" → 编造；
  - 回复称"在XX公司/单位/事务所"（事实无单位名） → 编造；
  - 回复称"住在/家是X市"但与她事实市/省不符 → 编造；
- 发现矛盾 → **拦截**，替换为模板合规回应（avoid 级）。

---

## 三、实测结果（✅ 不再编造）

她的事实库（seed=20260827）：`出生福建福州；家庭小康（父母：医生、护士，离异，独生）；在读大学，在杭州`

| 用户问 | 她回答（基于事实，自洽） | 校验 |
|--------|--------------------------|------|
| 你有几个兄弟姐妹？ | "就我一个。不过也挺好的，一个人惯了。" | OK |
| 你爸妈做什么工作？ | "我爸是医生，我妈是护士。不过他们...已经分开好几年了。"（**连"离异"都自然地融进回答**） | OK |
| 你在哪里工作？ | "我现在还在读书，在杭州。" | OK |
| 你现在住哪个城市？ | "杭州...这里的秋天比福州舒服多了。" | OK |

**结论**：她说的每句话都有事实依据——"她是谁"由系统定义，LLM 只负责"怎么说"。这正是"隐藏宇宙"（人生真实存在，不编造）的落地。

---

## 四、已知边界（诚实）
- 校验器是**矛盾检测**（拦明确冲突）——"含糊回应"不会被拦（合理，那是她真实的防御）；但**"凭空编了但与她事实兼容"的细节**（如编"我养了只猫"）暂无法拦（乙的完整事实库可补）；
- facts 与记忆叙事的一致性（家贫 vs 医生家庭）未强校验 —— 乙或后续统一候选池派生彻底解决；
- **乙（完整事实库）**：把"她的一切可断言事实"做成硬库，LLM 完全无编造空间（本例已接近乙）。

---

- ✅ 甲（校验器）已实现并验证；
