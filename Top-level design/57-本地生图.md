## 〇、需求（协作方 2026-09-02 确认）
1. **路线 A：本地生成**（SDXL 图生图——她的本体图 → 她日子的照片）；
2. **频率看她的心情**：想发就发、不想发就不发（不是定时任务）；
3. **真实的不完美**：生气不发；倦怠/低落可能发"空桌子"（她不想被拍/没心情）——允许。

## 一、架构
```
日子引擎（她今天发生了什么）→ photo.decide_photo（想不想发 + 发什么）
   → prompt = 形象卡（她的长相，事实层） + 场景（日子关键词） + 风格（手机随手拍/不摆拍）
   → img_gen.img2img（RealVisXL，4GB：fp16 + attention/vae slicing + CPU offload，~30-90s/张）
   → data/photo_cache/*.png → QQ（file_type=1 图片；与语音共用隧道静态服务 /photo/）
QQ tick 时：照片（首选）→ 语音 → 文字——她"心情"决定形式
```

## 二、决策机制（photo.py，✅ 11/11 回归）
- **生气 → 不发**；**倦怠 → 不发**；
- **关系越深 × 依恋越深（touch_freq）× 心情** → 越想给你看她的世界（初识 5% → 深入 22% 起步）；
- **日子紧（烦/累）** → 概率大幅下调；**若发 → 发"空桌子"**（真实的不完美）；
- **每天一决定**（盐=种子×相处次数×今天）：她今天想不想给你看，定了就定了；
- **场景 = 她日子说了算**：加班→夜晚街景；雨→屋檐下；旧书店/猫/煮面/失眠/买菜…都有对应画面
  （`.life_log` 最近 5 天 + 日子基调）；没事件 → 窗边看书。

## 三、提示词原则
- **形象卡**（与 facts 一致：二十出头、及肩黑发没打理、素颜、白T+素色外套、安静）；
- **风格**：手机随手拍的真实照片 / 日常光线 / 自然不摆拍 / 生活感 / 允许暗角轻微糊；
- **负面**：网红脸、精修、AI 塑料感、摆拍、影楼、水印、多余手指、畸形。
- 她不是广告大片——**"活着的粗糙"是允许的**。

## 四、文件
- `moshi/img_gen.py`：SDXL 懒加载 + `img2img()` + `base_image()`（本体图）；
- `moshi/photo.py`：`decide_photo()` / `make_photo()` / 场景池 / 形象卡；
- `moshi/qqbot.py`：`/photo/` 静态路由 + `_try_photo_push()`（tick 首选照片）。

## 五、模型路线（实测决定，诚实记录）
- **实测 SDXL（RealVisXL）在 4GB：182s/张**（8s/步）——太慢，弃作默认，留作"画质慢路线"（SDXL_DIR）；
- **选定 SD1.5 · dreamshaper-8：512×768×20步 ≈ 17s/张**（fp16 整卡 3.4GB，不需要 offload）——"随手拍"节奏；
- majicMIX realistic（更写实的 SD1.5）镜像下载失败（hf-mirror 对此仓库不稳）——**代理直连 HF 是可靠路径**
  （`HTTPS_PROXY=http://127.0.0.1:6478`，已验证 4GB 高速成功）；
- **坑**：① diffusers 默认在 CPU 上跑（忘了 `.to("cuda")` → 20 分钟不出图，已修）；
  ② NSFW 安全检查器对写实人像极易误判黑图 → `safety_checker=None`（图仅自用）；
  ③ snapshot_download 末尾偶发 LocalEntryNotFoundError（文件其实已落盘，忽略即可）。

## 六、实测纪要（本轮真实发现，供决策）
1. **决策层可靠**（11/11）；引擎 40-60s/张（640×832×32 步）；
2. **提示词公式（关键）**：英文**关键词式** + CFG≈7 + 负面压 `people/woman/girl` + 无人物——"深夜泡面"已验证完美；
3. **模型先验问题**：dreamshaper 对部分场景（猫/窗边书）会**擅自塞人**（实测"猫"出窗边男人）；
   RV51 试过更糟（NSFW 微调语料，输出海滩内衣）；majicMIX 下载不稳（镜像 5 次失败）；
4. **人像哨兵已建**：DeepSeek vision 判"照片里有没有人"（实测人图→有✅ 泡面→无✅），
   make_photo 自动换种子重试（≤3 次）；
5. 诚实结论：**SD1.5 小模型的场景服从度不稳**——要稳做"她的世界"照片，正解是
   **IP-Adapter（SD1.5 版，4GB 可行）**或**换写实底模（majicMIX，需换下载通道）**；
   当前已可先跑稳定场景（night_desk 等按哨兵过滤后输出）。
