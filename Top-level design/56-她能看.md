# 56 · 她能看：vision 接入（照片进对话）

> 记录日期：2026-09-02（会话进行中）

## 〇、做了什么
她从此**能看到你发给她的照片**（QQ 单聊/群聊图片）：
```
QQ 图片（attachments[].url）
  → 本机下载 → data:image/jpeg;base64（或原 URL 兜底）
  → DeepSeek 多模态（deepseek-v4-flash-vision-exp，内容为 [text, image_url]）
  → 她按人格回应（可以就着照片说点什么，也可以闷着不提——像她）
```

## 一、实现（5 文件）
- `moshi/v4/llm.py`：`generate_reply_llm(..., image_url=)` → 多模态 content；system 加一段
  "对方给你看了一张照片——像平常的你那样"（它可以评论/好奇/什么都不说）；
- `moshi/v4/dialogue.py`：`generate_reply(..., image_url=)` 透传；
- `moshi/runtime.py`：`Session.on_message(text, image_url=None)`——纯图片消息也接（text 补"（给你看一张照片）"），
  **她看过照片 → 记入 chronicle**（special：你给她看过一张照片）；
- `moshi/qqbot.py`：`_image_data_url(message)`（附件过滤图片类型 → 下载 base64，失败回退原 URL）；
  纯图片、图文消息都进框架。

## 二、回归 ✅
- 纯图片（无文字）→ 有回应；图文 → 有回应；无图聊天不受影响；
- **"看没看见"的诚实验证**：中性提问直连模型 → 正确答出图内文字"默识""喵"+ 浅蓝圆（证明链路是实的，
  不是模板敷衍）；
- chronicle 入档；图片不落盘存储（仅进 prompt，无泄露面）。

## 三、边界（下一步可扩）
- **只做了"她能看"**；"**她给你看她今天**"（她发生活照片）需要**图像生成**能力
  （即梦/可灵 API 或本地 SD/Flux——待定，属下一阶段）；
- 群聊图片也走同一链路（已验证接口形态，实际效果待群里试）；
- 视频/语音消息暂不支持（后续 vision 视频/ASR）。
