- model：`deepseek-v4-flash-vision-exp`

**实现要点**：

- **边界归规则**：LLM 只负责"以她的口吻生成自然语言"；**允许披露什么（隐藏宇宙边界）由规则层决定**（dialogue 的披露等级），prompt 里给 LLM 明确的"允许程度"；
- **失败降级**：无 key / 调用失败 → 自动降级到规则模板（不崩，提示）。

## 二、真实人际披露模型（dialogue.py 重构）

**核心**：不会因一句"你家在哪"就聊起过去。披露取决于五因素：

| 因素 | 含义 | 权重 |
|------|------|------|
| 信任度 | 交互积累 | +0.25 |
| **对等性（reciprocity）** | 你也敞开过自己 | **+0.35**（最重要） |
| 场合感 | 问题是否自然从话题浮现（聊了几轮/连续话题） | +0.25 |
| 侵入性 | 问题多冒犯（名字=低；背叛/感情史=高） | −0.20 |
| 疼痛度 | 记忆的"伤疤"程度（背叛/受伤=高痛） | −0.15 |

**三档结果**：
- **轻带过（avoid）**：默认，未达门槛（真实人初识：问过去→回应一点点但转移/反问）；
- **浅露端倪（hint）**：部分达标（信任/对等够时）：说一个无害细节，收着；
- **深谈（share）**：信任高+对等强+时机好+疼痛可承受：才具体讲。

**实测验证**：
- 初期问"你家在哪"→ avoid（不会说）✅；
- 你先分享了自己（对等性 0.5）+ 信任 0.7 → "你家在哪"→ hint（露端倪"5岁窝在被子里…"）✅；
- 问"你曾经被背叛过吗"→ 即使信任够也 **avoid**（高侵入+高疼痛）✅ 真实。

## 三、真实调用效果（DeepSeek 以"陈默识"口吻回复，已实测）

```
你> 你平时喜欢做什么？
她> （轻轻笑了下）我喜欢看花，尤其是路边的野花。不贵，好看，还不用养。你呢？

你> 你小时候怎么样？   （avoid等级）
她> （轻轻笑了一下）我小时候啊...考过第一。那时候觉得挺开心的。（停顿片刻）对了，你平时喜欢做什么？

你> 你曾经被背叛过吗   （avoid等级，高侵入）
她> （轻轻抿了抿嘴唇）背叛啊...（停顿了一下）我更记得的，是曾经等过很久的人，始终没有来。
```

**这不是模板了**——有停顿、话题转移、含蓄回避、性格（"路边的野花不贵好看不用养"暗含她对负担的谨慎）。

## 五、已知边界（诚实）
- **对等性识别**靠"用户消息含'我'且较长"的简单规则（V4 简化），真实系统需更细（你说了什么、她是否回应）；
- **披露模型的分数/阈值**目前手感校准（0.30/0.50），可随实测微调；
- 意图分类仍为关键词（"你现在还想相信人吗"类语义问题靠 LLM 补充）；
- thinking 模式开启但未利用其"思考内容"（V5 可利用推理结果提升一致性）。
