# 42 · 关系网自适应 + 隐藏宇宙（配角随生活情境、不可审阅）

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并实测 ✅（混沌敏感保持 12.2 亿倍 / 回归正常）
> 背景：协作方指出两个根本问题——①配角是"定好的"，不适合默识换环境（新同事/新朋友不会增加）；
> ②直接设定 = 用户知道了她的关系网（违反隐藏宇宙）。
> 确认方向：**甲（配角随生活情境自适应 + 完全隐藏）**。

---

## 〇、两个问题与解决

| 问题 | 解决 |
|------|------|
| 配角"定好的"，不随环境变 | **自适应生成**：配角由"生活情境"（在校/工作/住所/兴趣）动态确定 |
| 设定即让用户看了她的世界 | **完全隐藏**：配角是系统侧；用户**看不到**网络，只能对话得知（她按信任/时机提起） |

---

## 一、自适应（relation_templates_for / update_relations_for_context）

配角由生活情境推导（`relation_templates_for(facts, memories)`）：
- **在校（宿舍）** → 室友 / 学生时代朋友（记忆）；**已工作** → 同事；
- 兴趣（旧书店）→ 店主；住所 → 楼下橘猫/邻居；家庭 → 妈妈/手足。

**update_relations_for_context**：生活情境变 → 配角**自动增删**：
- 毕业 → **室友淡出**（宿舍没了）；工作 → **同事出现**；
- 兴趣/住所变 → 对应配角增删。

### 实测（✅ 随环境自适应）
| 情境 | 她世界的配角 |
|------|-------------|
| 在校 | 妈妈 / 室友 / 旧书店老板 / 楼下橘猫 |
| 毕业工作后 | 妈妈 / **同事（新）** / 楼下橘猫（室友/旧书店淡出） |

---

## 二、完全隐藏（隐藏宇宙）

- **demo 从不展示**"她世界里的人"（只有临时测试脚本列过，已删；主 demo 只构建供 LLM 提问，不打印）；
- 用户**只能对话得知**：你问"你室友/同事"，她按**信任/时机**提起（披露模型管——刚认识不说）；
- **你拼出她的世界，而非审阅**——这正是"隐藏宇宙"的体验（像认识真人：你从相处里得知她生活里有谁）。

---

## 三、意义
- **她世界是"活的"**：随她生活流动（换环境→新朋友出现、旧的淡出）——像真实人生；
- **隐藏宇宙守住**：你永远无法"看"她的网络，只能"相处得知"——这保住了"她是一个独立的存在，不是被你审阅的对象"。
