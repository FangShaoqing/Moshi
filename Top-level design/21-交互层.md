# 21 · 交互层（V4）—— 相遇：你遇到"当下的陈默识"

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并运行验证 ✅（最小命令行版本）
> 背景：项目从"造人"（V0-V3）走向"相遇"（V4）。这是"隐藏宇宙"体验真正落地的一层：
>   你认识的是当下的她，她的过去只在对话中偶露端倪——通过相处拼出她是谁。
> 定位（协作方确认）：**乙** —— 她不"知道"自己的人生档案，只记得经历的事 + 有性格。

---

## 〇、设计（三层 + 关键决策）

```
生成侧（V3）→ seed → 出生日期/人格(认识)/人生轨迹
      ▼ 加载"她"
交互侧（V4）
 1. 记忆层   ：她"记得"的事（大事年事件 + 性格认识）——乙：无全知档案，只记得经历
 2. 人格层   ：运行时她（记忆 + 性格 + 当前情绪状态 + 与你的信任度）
 3. 对话层   ：意图分类 → 记忆检索 → 人格过滤 → 回应生成（混合）
```

**关键决策（协作方确认 + 我的倾向）：**
- **分叉 1 = 混合（C）**：**规则定"边界"**（她允许说什么/回避什么——隐藏宇宙），**LLM 可插拔给口吻**；无 LLM 时规则模板兜底（MVP 最小可跑）。
- **分叉 2 = 记忆 + 信任**：被问到过去 → 凭记忆（有依据）回应；信任度决定深浅（初只露端倪，信任渐深说更多/更深）。
- **分叉 3 = 最小命令行对话**（`moshi/v4_demo.py`）。
- **定位乙**：她不会"盘点自己"（不主动说"我的人生经历是..."），只凭记忆和性格回应。

## 二、验证结果（✅ 相遇机制成立）

模拟对话（seed=20260827，她 20 岁）：

| 用户问 | 她回应 | 观察 |
|--------|--------|------|
| 你好 | "嗯，我在。心情还不错。你呢？" | greeting ✅ |
| 你叫什么名字 | "我叫陈默识。至于别的嘛……先说你的？" | 乙：带迟疑 ✅ |
| 你家在哪 | "嗯……5岁，窝在被子里听到家人脚步声…具体的，以后再说吧" | **露端倪、不全说**（隐藏宇宙）✅ |
| 你小时候怎么样 | "7岁，考了第一，努力是有回报的……好像一直没过去" | 泛指→想起最鲜明的事 ✅ |
| 你以前有没有相信过一个人 | "2岁，说好来接她的人没来……好像一直没过去" | 信任渐深→更深的记忆 ✅ |
| 你觉得钱重要吗 | "嗯……嗯。我话不多，但你说的话我听着的。" | chat 兜底 ✅ |

**信任从 0.28 渐升到 ~0.7** —— 她一点点敞开，但始终"只露端倪、不全盘"。

## 三、过程中的调试（诚实记录）

1. **"你好"回复病句**（"今天有点心情还不错"）→ 模板拼接错，已修。
2. **信任涨太慢/阈值过硬 → 永远回避** → 调整：信任涨幅 + 阈值放宽 + **"被问到相关记忆就露端倪（即使信任不高）"**——真实的人对陌生人被问到过去也会稍作回应。
3. **意图分类关键词冲突**（"你现在还想相信人吗"被归为 ask_now，因为"现在"）→ 改为"过去类词优先" + 长词优先，并把"相信人/信任"等加入过去类。
4. **泛指问题（"你小时候怎么样"）检索空** → 兜底：无领域匹配时，她"想起最鲜明的事"（vividness 最高记忆）。
5. 我在 dialogue.py 再次写了 `if False` / 未定义函数占位（坏习惯又犯）→ 已清理。

## 四、已知边界（诚实）

- **规则引擎固有限制**：语义理解靠关键词（"你现在还想相信人吗"这种需要 LLM）——MVP 可接受，真实系统接 LLM（`MOSHI_LLM` 回调接口已留）。
- **模板口吻生硬**——LLM 插拔后由大模型以"她的人格+记忆"生成，会自然很多。
- **信任演化简单**（每次 +0.03~0.08）——真实系统需更细腻（关系进展、她的防御、你的行为如何影响她）。
