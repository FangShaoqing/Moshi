## 〇、设计核心：数据与种子绑定 + mode 隔离 + 一键删档

```
moshi/
└─ data/
   ├─ SHE_<seed>/            ← 每个种子一个目录（数据与种子绑定，互不干扰）
   │  ├─ state.json          （她：信任/情绪/关系阶段/记住你的事/特殊记忆 + mode）
   │  └─ history.json        （你们的对话历史）
   └─ clear_data.py / python -m moshi.clear_data  （验证期一键删档）
```

### 关键机制
| 机制 | 实现 | 效果 |
|------|------|------|
| **同种子续接** | 启动 `load_person`（有数据则恢复她/历史）；退出 `save_person` | 退出不丢，下次续接（她记得你、关系继续） |
| **换种子隔离** | 数据在 `SHE_<seed>/`；不同种子无交集 | 种子变 = 全新她（不合污） |
| **mode 隔离** | state.json 带 `"mode": "verify"`；正式版 `load_person(allow_verify=False)` 检测到 verify → **拒绝加载+警告** | 验证期数据不会被正式版误用 |
| **一键删档** | `python -m moshi.clear_data` 清空所有 SHE_*/ | 验证期测完即清，保证不污染 |

## 四、意义（最后一次"基石"）
