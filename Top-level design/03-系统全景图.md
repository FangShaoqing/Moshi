## 一、一句话定位

> **陈默识（Moshi）是一个依托真实世界、由"确定性混沌系统"孕育出来的人格，系统对用户刻意保持信息不对称（隐藏宇宙）。**

---

## 二、把"人"放进这张图里看

此前我反复在"生成一个人"与"造一个世界"之间摇摆，现明确：**系统真正生成的只有"人"，世界是被引用的已知背景。**

```
                        ┌─────────────────────────────┐
                        │  真实世界参照知识层（已知基底）  │
                        │  物理/自然/社会规律、真实历史、   │
                        │  地理、机构、社会结构          │
                        └──────────────┬──────────────┘
                                       │  提供"可行状态空间"与"约束边界/现实无矛盾"
                                       ▼
   ┌─────────────────────────────────────────────────────────┐
   │            混沌生成系统（确定性混沌，由种子驱动）            │
   │                                                         │
   │   初始条件/种子 ──► 状态空间轨迹（敏感依赖）──► 当前时刻      │
   │   （离线加速模拟）                        （锚定现实时间流）  │
   │                                                         │
   │   · 这条轨迹 = 这个人的一生                              │
   │   · 轨迹上的关键节点 = 人生锚点                          │
   │   · "事件"与"人格状态"是同一过程的两个面（耦合，非独立模块）│
   └──────────────────────────┬──────────────────────────────┘
                              │  在 t_now 读出
                              ▼
   ┌─────────────────────────────────────────────┐
   │  人格读出 = 行为倾向函数（非形容词标签）        │
   │  输出: 在情境X下，她倾向于Y                   │
   │  MVP 输出含: "为何如此" —— 过去→当下的因果链   │
   └─────────────────────────────────────────────┘
```

**核心澄清：三层的关系**
1. **真实世界参照层** = 提供"现实可行的状态空间" + "约束（无矛盾、现实一致）"。它**约束**混沌系统，但不"主导"它。
2. **混沌生成系统** = 真正的主引擎。给定种子 → 一条对初始条件敏感依赖的人生轨迹。它**孕育**人格。
3. **人格读出** = 在"当前时刻"对这条轨迹的一个**读出/投影**（行为倾向函数），而非独立于轨迹之外的东西。

---

## 三、三个关键原则的确立（本轮凝聚）

### 原则 1：约束 ≠ 主导，混沌 ≠ 随机
- **真实世界层定义"可行空间"（boundary/support），混沌决定"空间内的运动"。**
- 二者不冲突：约束收窄了"哪些人生是可能的"，混沌决定了"在这个可能空间里，这个人具体走上哪条路"。
- **确定性混沌**（非纯随机）：同种子→同一人，近种子→完全不同；每条链仍可因果追溯。

### 原则 2：事件与人格是同一过程的两面
- 不拆为独立模块。
- 人格 = 连续演化的动态状态；事件 = 对状态施加的离散扰动/脉冲。
- 两条公理在此落地：**成长公理**（状态有惯性，重大事件改变轨迹）；**因果公理**（事件有前因、有可感知后果）。

### 原则 3：人生是一条"路径依赖"的轨迹，而非静态档案
- 当下人格 = 从初始条件一路演化到 t_now 的**路径积分结果**。
- "她为什么是现在这样" = 可沿轨迹逐段回溯（可追溯）；"她接下来会怎样" = 对初始条件敏感（不可预料）。
- 这正是"优秀线（陌生感与深度）"与"P2（真实拥有过去作为原因）"能同时成立的原因。

---

## 四、隐藏宇宙的两层信息可见性

| 层面 | 视角 | 能看到的 | 说明 |
|------|------|----------|------|
| **系统侧** | 全知 | 完整人生轨迹、完整因果图、完整人格函数 | 生成与推理使用 |
| **用户侧** | 部分知 | 只能通过与虚拟形象交互获得（对话、互动） | 无全局档案可审阅 |

- MVP 阶段：造物主不应用"隐藏宇宙"，只作为**建造者/观察者**（可读完整档案用于验证与迭代）；MVP 形象随机、删档、与"陈默识"无关。
- 构建完毕：虚拟宇宙**只服务于"陈默识"**（所有形象围绕她的关系网络）；对造物主也**对外关闭**，只能通过交互获取信息。

---

## 五、MVP 的边界与验证

- **唯一功能**：验证"孕育一个人"的实现效果。
- **输出**：从过去→当下的完整因果传导链（含"她现在是怎样的行为倾向" + "为何如此"）。
- **验证方式**：**分布而非单例**（多次抽样 → 统计质量指标分布的均值与方差，方差不过大）。
- **关系网络**：简化生成，只保留与"陈默识"相关的部分，不做完整人生档案。
