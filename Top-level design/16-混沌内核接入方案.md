## 〇、先验证的事（已完成 ✅）

`moshi/chaos_lab.py` 用最经典的 Logistic 映射做了**独立、可验证的敏感依赖演示**：
- **混沌区 r=3.99**：微扰 1e-9 → 40 步后差值 0.75（放大比 ~7.5 亿倍）→ **敏感依赖成立**。
- **稳定区 r=3.2**：微扰 1e-9 → 衰减为 0 → 对照（非混沌）。

**结论**：真混沌需要**拉伸机制**（x(1-x) 非线性），而 V3 之前只有**收缩机制**（α回归 + tanh饱和 + clamp）→ 微扰被衰减。**这不是"加个 tanh"能解决的，需要明确引入拉伸。**

## 一、接入方案：**混沌内芯 + 调制事件涌现**

### 思路（为什么这样接）
- V3 的 6 维状态动力学（世界反馈/事件涌现/波动）**不能破坏**——要继续保留。
- 混沌**不直接替换** 6 维动力学，而是作为**一个"内在混沌内芯"**（核心天性的脉动），**调制**事件从哪里来、以什么强度发生。

### 结构
```
混沌内芯 c_t（1 维，Logistic 型，r≈3.9+，确定性）
    │  c 微扰 → 数十步后完全分离（敏感依赖）
    ▼
调制器 M(c_t)：
    → 决定"此刻事件偏向哪个领域" + "事件强度偏移量"
    ▼
叠加进 V3 事件涌现（_active_domains 的权重 / _delta_from_world 的强度）
    → 不同初始微扰 → 不同的事件序列 → 不同的人生走向
```

### 为什么这样能"既混沌、又不破坏已有成果"
| 已有成果 | 是否保留 | 如何保留 |
|---------|---------|---------|
| 世界反馈（世界起伏/支持打击） | ✅ | 世界响应 r 不变，继续作为"外部环境" |
| 波动性 | ✅ | 仍由世界反馈+回归产生 |
| 事件涌现 | ✅ | 仍由"状态×世界"动态决定；混沌内芯只*调制*其强度/偏向 |
| 确定性可复现 | ✅ | 混沌内芯由种子初始化、确定迭代 |
| **敏感依赖（新增）** | ✅ | 混沌内芯微扰 → 指数放大 → 影响事件序列 → 人生分离 |

**关键原则**：混沌不是"让数值乱跳"（那会破坏可读性），而是"**让命运走向敏感依赖微扰**"——微扰只在"长程传递"后体现为**不同的人生事件**，每个事件本身仍可读、可解释、仍在合法状态格内。

## 三、为什么这比"直接把 tanh 放大"正确（诚实反思）

- V3 的失败不是"tanh 不够强"，是**动力学结构里没有"拉伸"**——tanh 是饱和（收缩），不是拉伸。
- Logistic 内芯 `c'=r·c(1-c)` 是**确定性的拉伸-折叠**，它本身就是混沌标准型。
- 接入方式用"**内芯调制事件**"而非"把值加进 6 维"——因为 6 维是"她这个人"（要稳定可解释），而混沌应藏在"**命运进程的敏感依赖**"里（要敏感但不必解释）。
- **诚实说明**：这个内芯是"一维混沌 + 调制"，不是"6 维全混沌"——后者的数学难度和稳定性分析都远超当前阶段，不必要。**目前方案已经用可见的证据证明敏感依赖成立，且保住了已有成果。**
