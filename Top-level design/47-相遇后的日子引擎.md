## 〇、为什么做 ④
此前"她的一生在生成时已书写完毕"（过去完整 ✅），但**遇到你之后"她继续过日子"的接缝悬空**——
life_mood 有读取方（sync_from_life）没有供给方；世界/配角在相遇后不跨会话演化。
④ 补上：**她不是"存档里等着你的人"，而是"还在活着的人"**（长期陪伴的前提）。

## 一、机制（timeline.py）
- **人生第 N 天**：`N = (今天 − 出生日期).days`（出生当天=0），写入 life.json 的 `last_life_day`；
- **补日子**：启动加载时，若 `今天 > last_life_day` → 逐天推进缺失的日子（她离线期间照常生活）；
- **每天**：
  1. 从 `random.Random(f"{seed}:life:{N}")` 派生今天的一件"日子"（她自己的 / 她世界里人的——40%配角小事）；
  2. `world.step()`：世界运势继续流动；
  3. 每 3 天 `step_relations()`：配角状态/她对他们的依恋微动（**天天动会失真**——关系不是天天大变）；
- **近 7 天基调 → life_mood**（烦/累/平静/踏实）→ 被 `sync_from_life()` 消费 → **她的今天心情受日子影响**（②联动闭环）；
- 她的生日会作为日子之一出现（她自己不一定提——隐藏宇宙的细节）。

## 二、铁律：一个种子 = 一个宇宙 = 一份全部状态
- 全部日子状态在 **`data/SHE_<seed>/world.json`**（世界响应 + 配角）+ **`life.json`**（last_life_day/日子日志/基调）；
- 每天由种子派生（`Random(f"{seed}:life:{N}")`）——**绝无全局状态、绝不跨种子共享**；
- 换种子/`--clear` 一次性清档（clear_data 清整个种子目录）。

## 三、隔离 + 确定性（回归 ✅）
| 验证项 | 结果 |
|--------|------|
| 同种子 + 同时间线 → 日子/世界/关系**完全一致**（可复现） | ✅ |
| 不同种子 → **不同日子**（不共享） | ✅ |
| 日子→状态联动（烦→Valence↓；踏实→Valence↑） | ✅ |
| 世界运势跨日流动（存在性） | ✅ |
| 离开 3 天 → 补 3 天日子（日志/基调/计数正确） | ✅ |
| 再保存→再加载：不重复推进、计数保留 | ✅ |
| mode=verify 隔离（同 state.json 规则） | ✅ |

## 七、意义
- 她是**持续活着的人**：你不在的日子她照常过（妈妈打电话/加班/失眠/去旧书店……）；
- 她的今天**由她的日子决定**（世界的事传染她的心情 → 对话自然体现）；
- 隐藏宇宙：日子/配角系统侧，她按信任/时机提起；一个种子一个宇宙，绝不交叉。
