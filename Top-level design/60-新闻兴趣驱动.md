# 60 · 新闻：兴趣驱动（她看不看新闻，从她的人格里长出来）

> 状态：完成并验证 ✅（确定性/人格差异/心情调制）

## 〇、为什么改
原设计"每天获取新闻"是**写死**的——但真实的人不看新闻（尤其她：话少、不凑热闹、对外界留一手）。
**是否获取 = 她的关心程度**（像"她话多不多"一样从人格长出来），不是说新闻线每天必须跑。

## 一、关心度模型（news_interest，0~1，种子派生）
| 信号 | 影响 |
|---|---|
| 职业/专业：新闻传播/记者/媒体/编辑/新媒体 | **0.75**（她的工作就是看新闻） |
| 文科/书/画/写/设计/文化 | 0.45 |
| 软件/运营/电商/科技 | 0.40 |
| 会计/行政/营销/护理/教育 | 0.35 |
| 一般底子 | 0.30 |
| 信任底色"怕再错付/留一手/不敢" | **−0.12**（对世界保持距离 → 少看） |
| 缺点"为以后焦虑/想太多" | +0.10（民生就业多瞄两眼） |
| 缺点"心里有事不说/藏" | −0.05 |
| 心情（日子紧 烦/累） | 当天 ×0.6 |
| 倦怠（exhausted） | 当天不看 |
- 确定性：`Random(f"{seed}:news:{day}")` 每天一次判定（她想看才看）。

## 二、实测（90 天采样）
| 人 | 关心度 | 90 天里"想看"的日子 |
|---|---|---|
| 她（seed 20260901，汉语言+信任留一手） | 0.33 | **34 天**（约每 3 天看一次——有一搭没一搭） |
| 媒体人（新闻传播·编辑） | 0.75 | **62 天**（几乎天天——职业） |
| 普通人 | 0.30 | ~27 天 |

## 三、行为
- 她决定看的今天：取池 → 领域打分 → 最多 2 条（领域优先/民生补位）；
- 她决定不看的今天：**没有新闻条目**（提示词里就没有——她今天不知道，真实）；
- 数据源仍然是综合新闻一个接口+社会保底；缓存/不播报原则不变。
