# V3 修复 · 表现层/叙事层（年龄错位 + 事件空洞）

> 记录日期：2026-08-30（会话进行中）
> 状态：代码已改（world.py + engine.py），**待运行验证**（会话沙箱临时目录故障，无法由助手运行）。
> 背景：协作方看 V3 输出后说"感觉怪怪的但说不出哪里不对"。经分析定位出 4 个表现层问题：
>   ① 年龄错位（幼童经历"工作与生计"）；② 事件空洞（"发生了一件事"占位符）；③ 输出像数据报告；④ 无平淡期。
> 协作方确认：① 和 ② 最怪。本次只修这两个（③④ 待后续）。

---

## 一、根因（诚实反思）

V3 把精力集中在"演化内核"（动力学/混沌/世界反馈）——这块**现在是真的**；但**表现层/叙事层被忽略**：
- 世界模型选领域时**完全不看年龄** → 9 岁孩子也经历"工作与生计"；
- 事件渲染退化为"在「领域」上发生了一件事"（占位符）→ 从"有故事"退回"有数据"。

**教训**：引擎的"演化真实性"和"叙事的可读性"是**两件事**。V3 做好了前者，丢了后者——"她这个人"不见了。

---

## 二、修复 1：人生阶段闸门（年龄-事件适配）

`world.py` 新增 `DOMAIN_AGE_START`：每个领域**最早可发生年龄**，作为合法状态格/真实世界约束的一部分：

| 领域 | 最早年龄 | 说明 |
|------|---------|------|
| 信任 / 归属 | 2 | 依恋期就有 |
| 自我价值 | 5 | 学龄前"我行不行" |
| 表达自我 | 6 | 小学"敢不敢说" |
| 未来 | 12 | 青春期想"以后" |
| 金钱 | 14 | 青春期体会钱的分量 |
| 亲密关系 | 15 | 青春期后期 |
| 工作与生计 | 16 | 成年前后 |

`engine._active_domains` 过滤：`W.can_domain_happen(d, age)` 允许的领域才参与 → **幼年不会再发生"工作与生计"**。

---

## 三、修复 2：事件有质感（具体叙事渲染）

`world.py` 新增 `EVENT_NARRATIVES`：**领域 × 阶段（幼年/童年/青春期/成年）× 顺/逆风** 的具体叙事。

示例（每格 1-2 条，真实系统由大模型生成，V3 用模板）：
- 信任·童年·逆风 → "她最要好的朋友，把她的秘密说了出去"
- 归属·青春期·顺风 → "她找到了一个能说心里话的地方，终于不那么飘着了"
- 自我价值·成年·顺风 → "有人告诉她'你值得'，她半信半疑，但心动了"

`engine._note` 改用 `W.render_event(domain, age, favorable)`：按"主情境 + 世界顺/逆风"渲染成具体的一件事。**favorable 由世界响应 r 决定**（r>0 顺风 → 顺叙事；r<0 逆风 → 逆叙事）。

## 四、验证结果（✅ 已运行确认）

沙箱故障解除后运行 `python -m moshi.v3_demo`，结果：

| 验证 | 结果 |
|------|------|
| ① 年龄错位消失 | ✅ 3岁"食言"、9岁"举手"、15岁"把心里话说给一个人听"、18岁"喜欢上一个人"、21岁"为糊口工作" —— 年龄与人生阶段吻合 |
| ② 事件有质感 | ✅ 每条是具体的事（"被最亲近的人背叛，她第一次明白'交出去'的代价"），非"发生了一件事" |
| 1. 同种子可复现 | ✅ True |

| 3. 波动性 | ✅ True |
| 4. 事件涌现 | ✅ True |

**修复未伤及混沌内核**——四项验证全部保持，混沌敏感甚至更强（之前 0.094 → 现在 0.152）。

### 新发现的小问题（诚实记录）
- **叙事模板重复**：渲染表每格仅 1-2 条文案，同一句可能抽到 2 次（如"她鼓起勇气举了手"出现两次）。真实系统由大模型生成无限变化；V3 模板下可感，后续补几条变体即可（非结构问题）。
