## 一、完整事实库结构（Facts）

| 类 | 字段 | 候选/生成 |
|----|------|----------|
| 身份 | 出生地（省/市）、现居城市 | CITIES（真实省/市），40% 迁移 |
| 家庭 | 阶层、父母职业、兄弟姐妹、结构 | 阶层→职业映射；氛围→结构 |
| 求学 | 学校类型、就读状态、专业 | SCHOOL_TYPES/MAJORS；年龄决定在读/毕业 |
| 工作 | 职业 | 年龄决定（≤21 学生；≥24 工作1-3年） |
| 生活 | 住所、兴趣(2-3)、习性 | RESIDENCE/INTEREST/KEEPS 池 |
| 情感 | 感情状态 | 年龄+权重（读大学多单身；工作后可能恋爱中） |

**to_context()**：生成完整事实清单（如 seed=20260827：
`身份：女，出生在福建福州，现在在杭州 / 家庭：小康（医生、护士；离异，独生）/ 求学：在读大学，职业技术学院，专业新闻传播 / 工作：暂无 / 生活：学校宿舍；喜欢画画、听歌、逛旧书店；睡前看书 / 情感：单身`）。

## 二、实测（✅ 不再编造，且"她"更活）

| 你平时喜欢做什么？ | "挺喜欢画画的。有时候去**西湖边写生**"（杭州→西湖，事实融合） | OK |

| 你谈过恋爱吗？ | "没有。这个年纪，好像大家都在谈恋爱，但我总觉得自己还没准备好" | OK |
| 你养宠物吗？ | "没有。小时候我妈倒是养过一只猫，后来…后来就不见了" | OK |
