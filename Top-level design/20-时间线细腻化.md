# 20 · 时间线细腻化：年粒度 + 平凡/大事分层 + 具体年份

> 记录日期：2026-08-31（会话进行中）
> 状态：已实现并运行验证 ✅
> 背景：协作方要求"她的经历的时间点再细腻一点"。三个层次全部实现：
>   ① 时间粒度 3 年 → 1 年；② 平凡年/大事年分层；③ 事件带具体日历年份。

---

## 〇、需求回述
"时间点细腻"拆为三件事：
1. **年粒度**（每一年一个时间点，而非每 3 年）；
2. **平凡/大事分层**（大多数年=平凡，少数年=大事——真正在做日子，而非每 3 年必有一件大事）；
3. **具体日期**（事件带真实日历年月，而非只写"9岁"）。

协作方拍板：三层次都做。

---

## 一、实现（engine.py + generate.py + 展示层）

### ① 年粒度
- `EvolutionEngine` 默认 `step_years=3 → 1`：每一年一个时间点。
- 效果：20 岁人生 20 个点（之前 6-7 个）；混沌有更多演化步。

### ② 平凡/大事分层
- `run` 每步判定：**世界响应峰值 |r| ≥ 0.60 或混沌 bias 极极端（≥0.90）→ 大事年**；否则平凡年。
- **大事年**：完整事件回路（选领域→事件脉冲→叙事→可成锚点）。
- **平凡年**：仅微小日常扰动（|Δ|≈0.012，状态几乎不动），叙事为"生活片段"（"这一年平平淡淡，她像往常一样过完了"），**不固化成认识**。
- `LifeStep` 新增 `is_major` 字段（True=大事年）。
- 锚点判定改为"只在**大事年**内按 delta 排名取前 30%"（平凡年不可能成锚点）。

### ③ 具体年份
- `LifeStep` 新增 `year` 字段；`generate_person` 演化后按 `birth_date.year + st.age` 填充。
- 展示层显示"**2023年（18岁）**"格式，事件锚定真实日历年份。

### 展示层（多元宇宙）
- 只列**大事年**（平凡年折叠为"…… 其间还有 N 个平平淡淡的年份……"），重点突出、不刷屏。

## 二、验证结果（✅）

| 验证 | 结果 |
|------|------|
| 年粒度 | ✅ 20-26 岁人生 20-26 个时间点 |
| 平凡/大事分层 | ✅ #2：25 年只有 9 个大事年；认识仅 3 条（少而深保持） |
| 具体年份 | ✅ "2019年（18岁）家里为钱吵了一架" |
| 时间线质感 | ✅ #1：2007-09 信任被破坏 → 2012 努力有回报★ → 2015-18 被看见★ → 2024 再信一次赌对★ —— 有起伏、有转折、有平淡 |
| 混沌四验证 | ✅ 可复现/敏感/**6.17 亿倍**/波动/涌现（年粒度步数多，敏感依赖增强） |

**惊喜（诚实鼓励）**：年粒度反而**大幅增强**了混沌敏感（1913 万 → 6.17 亿倍）——因为更多演化步给微扰更多放大空间。

## 三、一个小注意（诚实）
- 事件叙事目前仍基于"年龄段模板"（幼年/童年/青春期/成年），与"年粒度"匹配良好；
- 具体年份 = 出生年 + 年龄（未精确到生日前后月份）——对"时间点细腻"已够真；若将来需要"2015年6月"这种精确月，可在 LifeStep 加 month 字段（出生月+年龄推算）。
